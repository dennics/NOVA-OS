# Roadmap

These are priorities, not dates or shipped features.

| Stage | Work | Acceptance requirement |
| --- | --- | --- |
| 0.2 stabilization | Resolve both staging failures; clean-host image build; dependency/license decisions | Unchanged ISO installs offline and boots normally; security/persistence checks pass |
| Hardware work | Named hardware fixtures, encryption, supported boot paths and recovery | Recorded per-device results; no generic support claim |
| Gaming integration | Steam, Proton, GameMode, MangoHud and explicit game profiles | Per-game compatibility and comparative measurements; anti-cheat remains title-dependent |
| Recovery/Defender | Diagnostics, update source trust and recovery UI | Authorized operations, rollback and user-data preservation tests |
| AI/identity | NOVA AI and optional NOVA ID | Defined infrastructure, permission model and adversarial testing before execution features |

Earlier version labels 0.3/0.4/0.5 describe the intended sequence only. Reliable
installation and maintainable sources take precedence over expanding the UI.
